# Security Policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

Report it privately through GitHub: https://github.com/GeiserX/CashPilot-web/security/advisories/new

You will get an answer within 72 hours. Include what you found, how to reproduce it, and the version or commit you tested.

## Supported versions

Only the live site at https://cashpilot.club, built from `main`, receives fixes. A problem in the CashPilot app itself belongs in https://github.com/GeiserX/CashPilot/security/advisories/new.
